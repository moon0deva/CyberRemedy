HOW TO ADD YOUR LOGO
====================

1. Copy your logo file to this folder:
   CyberRemedy-v3/static/logo.png

   Supported formats: PNG, JPG, SVG, WebP
   Recommended size: 28x28 pixels (will scale automatically)

2. The dashboard will auto-detect and display it.
   If no logo file is found, the default ⚡ icon is shown.

3. To also use your logo in PDF reports, copy it as:
   CyberRemedy-v3/static/logo.png
   (same file — PDF generator reads from the same path)

4. To change the "CYBERREMEDY" text to your organisation name,
   edit dashboard/index.html and change:
     id="org-name">CYBERREMEDY
   to:
     id="org-name">YOUR ORG NAME
